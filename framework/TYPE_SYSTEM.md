# TYPE SYSTEM — 字号阶梯的字重映射 `W(S)`

SKILL.md §5.6 只留结论。本文件是它的完整依据，按需读取。

## 0. 唯一判据

一册 deck 只允许**一个** `字号 → 字重` 映射 `W(S)`。同一册里出现两个 `W(S)` = 无系统；
同一个 `W(S)` 在不同字号上取到不同字重 = 正常，不是混用。

## 1. 默认：重压型（Weight-forward）

| 角色 | 字号 | 字重 |
|---|---|---|
| hero / display | 76–180 | 800 / 700 |
| title | 54–80 | 700 |
| lead | 27–34 | 400–500 |
| body | 22–26 | 400 |
| caption / annotation | 15–20 / 14–16 | 600–700 |

- 层级由字重 + 紧行距承担。适合决策文档、投资案、董事会材料。
- 代价：每页超过 2 处重压就开始喊叫，读者没有休息的位置。
- 为什么：顾问式 deck 的读者是"扫页找结论"的，重字重能让结论在 20% 缩略图上仍然是一个黑块。

## 2. 逃生：反压型（Scale-forward，光学补偿）

| 角色 | 字号 | 字重 |
|---|---|---|
| hero / display | ≥76（投影 ≥100） | 250–400 |
| title | 54–80 | 400–500 |
| lead | 27–34 | 400 |
| body | 22–26 | 400 |
| caption / annotation | 15–20 / 14–16 | 600–700（唯一的加重区） |

- 为什么合法：字号上升时笔画相对面积同步上升，视觉重量天然变重。苹果为此给同一字体做了两套光学尺寸——**Display** 更细的笔画、更紧的字距用于大字号；**Text** 更宽的间距、更重的笔画用于小字。Helvetica Neue UltraLight 与 Bodoni hairline 是同一逻辑的另外两个血统。所以"越大越细 + 小字加重"是一套机制的两端，不是偏好。
- 反过来看更清楚：**小字用细体才是真错误**（笔画细到消失）。
- 适用：封面、章节页、宣言、画册、时尚/品牌、数字英雄页。

### 硬条件（不满足就不要用这套）

1. hero `≥76px`（投影 `≥100px`）且字重 `≥300`。`Thin(100/200)` 只许用在封面与数字，底色对比 `≥7:1`。
2. 标题字距收紧 `-0.5% ~ -2.5%`，行距压到 `1.0–1.08`；否则巨字细体会"散"。
3. 必须落在高对比底上（`≥7:1`）。细笔画在浅灰底上会直接消失。
4. 低 dpi 投影与喷墨打印会发虚——这两类介质下先渲染实测，再决定是否降字重。

## 3. 同样合法：单一字重（Uniform）

全册一个重量（`400` 或 `700`），层级只靠字号比 `≥1.6×`、留白与位置。Müller-Brockmann 的单字重海报与极简年报走这一路。代价：字号比不够时版面会糊成一片。

## 4. 常见误判

| 现象 | 判断 |
|---|---|
| 封面 `300` 巨字 + 内页 `700` 标题 | 合法，同一 `W(S)` 的两个取值 |
| 同为 `64px` 的两页标题一粗一细，无页型理由 | 混用 |
| 反压型里把 hero 加粗"让标题更有力" | 违反声明，等于把系统 A 塞进系统 B |
| 反压型里把注释压到 `300` | 违反光学补偿，`<14px` 更不可读 |
| 全册两套系统各占一半 | 无系统，返工 |
