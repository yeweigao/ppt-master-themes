# PHILOSOPHY — 本包的设计哲学，以及它凭什么比通用 ppt-master 更好

SKILL.md 只留结论。本文件说明三件事：包级设计哲学（所有主题共享的那一层）、本包相对 ppt-master 内置风格的六个提升杠杆、没有现成主题时怎么派生一个风格一致的方言。

## 1. 三层结构

| 层 | 是什么 | 在 ppt-master 里落到哪 |
|---|---|---|
| 包级哲学 | 瑞士国际主义网格秩序 × 先锋编辑叙事 × 有控制的解构切分 × 克制的新粗野结构感 | 写进每个 Style spec 与 Layout spec，由 Stage 2 读到 |
| Layout | 一套共享的结构库（目前是 `a4-editorial`：六轨网格、阅读区、图片槽、跨页关系） | Layout kind；装上后由 Strategist 为每页选原型 |
| Theme | 一种方言：设计哲学 + 主题基因（Theme DNA）+ 一组用共享 Layout 做的展示 | Style kind；展示样本在绘制阶段作校准 |

主题不是皮肤，是同一套哲学的不同方言。四个传统的出处与具体构造见 [Editorial Rhythm](EDITORIAL_RHYTHM.md) 和 [A4 Editorial Layout](../layouts/a4-editorial/README.md)。

## 2. 六个提升杠杆

ppt-master 内置的风格是形容词式的。以 `swiss-minimal` 为例，它写的是「模块网格、大量留白、单一无衬线字体、强字号层级、近乎零装饰」，没有一个数字，也没有结构、样本或评审方法。本包在同一方向上提供的是可执行的东西：

| 杠杆 | ppt-master 内置风格给的 | 本包给的 |
|---|---|---|
| 1. 精确参数 | 「模块网格」「强层级」 | 六轨 / 十二栏网格与具体页边距；字号阶梯、`W(S)` 字重映射、A4 印刷换算与 `14px` 底线；三级叠透 `1.0 / 0.58 / 0.34`；对比度阈值 |
| 2. 结构原型 | 空白页面，或 `presentation_core` 这类含卡片、KPI 仪表盘的通用原型 | A4 33 个、16:9 17 个经校准的结构原型，含跨页全景、解构蒙版、深色数字柱等模型不会自发想到的构图 |
| 3. 校准样本 | 无 | 主题展示页与已填充参考 SVG：尺度极差、换行节奏、裁切与叠透的真实做法 |
| 4. 整本节奏 | 单页视角 | 四种温度交替、全册至少 2 次由论证驱动的尺度突变、同构最多连续 3 页 |
| 5. 具名反默认 | 「避免装饰」 | 点名禁区：白卡片、KPI 瓷砖、图标墙、渐变阴影，以及模型自己的默认审美（米白底、标题斜体强调词、「01/02/03」编号标签、等宽标签、胶囊按钮） |
| 6. 评审→修正 | 通用质量门 | 四个大师视角的具体提问，以及「问题成因 → 改哪个变量」的修正对照（§4） |

前三个杠杆通过可安装的 spec 和原型进入 ppt-master 的规划阶段；后三个由本包的 SKILL.md 在规划与绘制时补上。评测方法见 [evals/](../evals/README.md)：同一 brief 分别用纯 ppt-master 与本包生成，按同一评分表比较。

## 3. 派生方言：没有现成主题时

用户要的风格不在主题列表里（例如「瑞士国际主义风」「建筑事务所作品集」），不退回通用风格，而是在包级哲学之内派生一个方言：

1. **先找最近的主题当底。** 例如瑞士风最近的是 `fashion`（它的 spec 本身就基于瑞士国际主义网格），战略类最近的是 `boardroom`。底主题提供网格、字号阶梯与评审标准；方言只改主题基因。
2. **填四个基因槽位，写成一句话一槽：**
   - 底场组：主阅读纸面色 + 转折深色底场 + 唯一高对比强调色；
   - 双声部：主张声部（标题、导语、大数字、引语）与证据声部（Kicker、刻度、直标、表头、来源），不混入第三种展示字体；
   - 唯一结构母题：从题材里只取一种贯穿全篇的微结构动作（刻度标尺、三级叠透、裸露粗实线画框、四角测绘括号、阶梯切角等择一）；
   - 节奏：在哪几种温度之间交替（例如满版影像 / 多栏精读 / 透明证据 / 深色转折）。
3. **把方言写进 ppt-master 已有的字段。** Default 写进 Stage 2 的自定义 visual style 行为与锁定的色彩、字体角色；Quick 留在当前上下文。不新增文件、不新增确认门。
4. **结构照用本包的 Layout。** A4 交付装 `a4-editorial`，16:9 交付装 `ppt169-editorial`，两者共用同一套六轨网格与结构哲学。
5. **值得复用时再入库。** 用户想保存这个方言，走上游 Create Template 的 Style 子流程，产出一个新主题目录。

## 4. 大师视角评审与修正

交付前用四个视角提问。它们是提问，不是清单：

| 视角 | 提问 | 常见成因 → 改什么 |
|---|---|---|
| 网格与动线（Müller-Brockmann） | 缩到 20%，第一眼落在计划的元素上吗？所有边缘对得上同一网格吗？ | 第一眼落错 → 移动重物或调整尺度极差；边缘不齐 → 回到网格轨道 |
| 排印与微观阅读（Ruder） | 字号阶梯在灰度打印下还分得出吗？导语、正文、注释各自守住了 `W(S)` 吗？ | 层级糊 → 拉开字号比（≥1.6×）而不是加颜色；孤字 / 两行半 → 按 [Copy Fit](COPY_FIT.md) 重断行 |
| 证据与图表（Tufte） | 每个数字有来源与基线吗？有没有不承载信息的墨水？ | 白底卡片、图例色块、多余网格 → 删；双轴 → 拆成两个图 |
| 节奏与张力（Brodovitch） | 联系表上整本有呼吸吗？转折页感觉得到吗？ | 连续同构 → 换温度或换载体；全册太平 → 加一次由论证驱动的尺度突变 |

按成因一次改一个变量，改源 SVG，只重渲染受影响的页。
