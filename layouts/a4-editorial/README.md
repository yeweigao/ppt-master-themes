# A4 Editorial Layout

一套适合 A4 竖版手册、宣传画册与阅读型资料的独立结构工作区。24 个原型共享一个 Master，每个原型对应一个不同的 Layout；页面可以选择、重复和重排，不规定整本内容顺序。

[工作区根](workspace/)为 `layouts/a4-editorial/workspace`。这是本主题包的扩展，不是 ppt-master 内置版式，也没有自动登记到它的全局库。

## 与主题和品牌组合

| 层 | 贡献 |
|---|---|
| Layout | A4 画布、六轨网格、文字与图片区域、占位符、跨页关系 |
| Style | 摄影叙事、阅读节奏、信息表达、开放式表格与背景气氛 |
| Brand | 真实标识、身份色、品牌字体及其使用规则 |

可以同时选择一个本 Layout、一个 Style 和一个 Brand。原型中的中性色、安全字体和临时字号只用于展示结构，最终身份与成品阅读尺度由项目确定。照片与示例文案不会成为后续项目必须保留的内容。

用户明确选择本包版式，或 Create Template 已在当前对话交付这个根时，将完整绝对工作区作为现有 Layout 类型的 `explicit` 输入；沿用所选 ppt-master runtime 的应用流程。传根目录，不只传内部 `templates/`；不因名称相似而搜索或冒充内置模板。

## 24 个版式

| 原型 | 构图与适合承载的内容 |
|---|---|
| `01_cover` | 大幅出血封面；标题与主图共同建立视觉重点 |
| `02_chapter` | 摄影章节页；章节号、短标题和引导文字 |
| `03a_content_dual` | 3＋3 双栏；连续阅读与并行短文 |
| `03b_content_sidebar` | 4＋2 主文与侧栏；正文配解释、数据或注记 |
| `03c_content_bottom` | 上部阅读、底部出血照片；让文字与宽景各有空间 |
| `03d_content_side` | 全高侧图与阅读区；适合竖向照片和短篇叙述 |
| `03e_content_spread_left` | 连续全景左页；与右页共享照片裁切坐标 |
| `03f_content_spread_right` | 连续全景右页；保留跨页延续与各页安全阅读区 |
| `03g_content_steps` | 分步信息模块；顺序、阶段与相应说明 |
| `03h_content_table` | 开放式数据区域；适合查阅表格及其说明 |
| `03i_content_gallery` | 摄影组图与题注；并置多个观察角度 |
| `03j_content_rhythm` | 无图节奏；2＋4 起笔、短焦点文字、跨栏摘句、错位双栏 |
| `03k_content_marginalia` | 锚定旁注；两段主文之间插入摘句，注释贴近所解释段落 |
| `03l_content_index` | 摄影索引；窄图与重复导航条目，便于快速进入内容 |
| `03m_content_masonry` | 六图瀑布流；列边固定、图片高度错开、底部统一收束 |
| `03n_content_stagger` | 交错图组；主图、细节和人物错开起点，文字进入安静区域 |
| `03o_content_contact` | 全景与接触印样；一幅横景统领两行六图 |
| `03p_content_overlay` | 图文跨界；独立标题跨过白边和照片，经局部底板保证可读 |
| `03q_content_geometry` | 摄影与几何场；大圆配重、主图与细节图形成前后关系 |
| `03r_content_evidence` | 结论与证据；4 轨证据对象、2 轨解释、来源和限定 |
| `03s_content_comparison` | 平行对照；两列三组对齐内容，仅横向分隔 |
| `03t_content_chronology` | 大字时间编排；短日期或阶段标签配事件描述，序列不代表时长 |
| `03u_content_typographic` | 文字主视觉；短标题大尺度、偏置小注、下方两种声音 |
| `04_ending` | 结束页；短句、联络信息或后续行动 |

第二辑的选型与细节方法见 [Editorial Rhythm](../../framework/EDITORIAL_RHYTHM.md)。节奏来自重复与变化、尺度反差、空间疏密和页面序列，不是给每个区块换颜色。示例中的照片、蓝金身份与具体英文均不进入安装清单。

六轨是对齐系统，不代表六栏正文。双栏、4＋2 或其他组合应由实际行长与阅读尺度决定；内容过量时换版、重组或续页，避免靠缩小文字塞满占位区。

跨页使用同一照片与同一总裁切区域，左页显示前半、右页显示后半。装订顺序是偶数左页、奇数右页；两页各自居中裁图不构成连续全景。关键人物、文字和细节避开中缝，拼接预览应核对地平线与主体连续性。

表格原型预留灵活对象区域，不固定项目数据、行列或费用字段。下游再根据内容构造原生可编辑表格；选择横线风格时，可见横线与原生单元格边框需一致。信息图同样在下游根据实际关系建立。

## 展示与导出

带照片、排好文案的 [本地展示](../../projects/a4_editorial_preview_20261020/) 用来观察真实密度、裁切与节奏。该目录被 Git 忽略，克隆仓库后未必存在；它不随工作区安装。可复用源位于 `workspace/templates/`，结构预览 PPTX 位于工作区 `exports/`，后者只作为评审证据。

规范画布为 `1240×1754`，但当前 ppt-master 导出器以 96 dpi 换算，格式名 `a4` 不自动保证物理 `210×297 mm`。需要真实 A4 时保留原始已验证导出，另存完整归一化副本：同时缩放 Master、Layout、Slide 的几何、文字和对象尺寸，再核查物理页宽高、占位对齐、实际字号及渲染效果。只改页面尺寸会破坏排版。

图片贴到画布边缘表示视觉出血；商业印刷所需的裁切外出血和 PDF 页面框仍按实际印刷要求处理。
