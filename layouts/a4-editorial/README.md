# A4 Editorial Layout

一套适合 A4 竖版手册、宣传画册、时尚 Lookbook 与阅读型资料的独立结构工作区。33 个原型（`01_cover`、`02_chapter`、`03a`–`03ad` 内容序列与 `04_ending`）共享一个 Master，每个原型对应一个不同的 Layout；页面可以选择、重复和重排，不规定整本内容顺序。

[工作区根](workspace/)为 `layouts/a4-editorial/workspace`。这是本主题包的扩展，不是 ppt-master 内置版式，也没有自动登记到它的全局库。

## 美学基因：瑞士国际主义 × 时尚先锋编辑 × 解构与新粗野张力

本版式库以**瑞士国际主义（Swiss International Style）**的数学网格为秩序骨架，融合**时尚先锋编辑（Avant-Garde Fashion Editorial）**的叙事气场，并在关键转折页引入**解构主义（Deconstructivism）**与**克制的新粗野主义（Restrained Neo-Brutalism）**张力：

- **瑞士国际主义网格秩序**：六轨（Six-track）与四列（Four-module）严密对齐、顶部字重/刻度坐标轴（Specimen Axis）、微字导引（Micro-kicker）与巨型陈列字（Hero Display）的尺度极差、无多余装饰的横线（Hairline）层级。
- **时尚先锋编辑叙事**：源自奢侈品牌年鉴与先锋画册的呼吸感——满版纪实/肖像摄影与高饱和单色块并置、巨幅通栏刊头字（Masthead）、冲孔档案卡（Die-cut Archive Plate）以及戏剧性留白。
- **解构主义切分与正负形**：将传统格纹解构为阶梯状实色与半透明棋盘格遮罩（`03x`）、让巨型衬线数字沿阶梯白柱右下边缘裁切出血（`03z`）、用水平切片与正负形剪影重构陈列大字（`03y`），以及在多图瀑布流顶部引入微倾切角破格（`03w`）。
- **克制的新粗野主义结构感**：摒弃冗余圆角与浮夸阴影，采用裸露的粗黑实线画框（Exposed Borders，`03q`、`03v`、`03y`）、硬朗的零圆角几何色块交叠与反转深色底场（Inverted Monolith，`03z`）。

## 瑞士国际主义字号、字重与阅读动线规范（A4 物理印刷校准）

`a4-editorial` 画布为 `1240 × 1754` SVG 单位，对应物理 A4 纸张 `210 × 297 mm`（`595.28 × 841.89 pt`），即 **`1 SVG 单位 ≈ 0.48 pt`**（约 2 个 SVG 单位等于 1 pt）。为确保印品实物的阅读舒适度与瑞士国际主义层级秩序，所有原型与下游主题均遵循以下五级阶梯，使**阅读动线与信息重要顺序严格匹配**：

| 视觉动线顺位 | 页面角色 | A4 SVG 字号 | 物理印刷字号 (`×0.48`) | 字重与排版规则 |
|---|---|---|---|---|
| **第一顺位（视觉锚点）** | 巨幅刊头 / 章节号 / 裁切数字 (`hero` / `display`) | `84–300 px` | `40–144 pt` | **Bold (`700`)**；建立全页第一视觉焦点与几何配重 |
| **第一顺位（核心论点）** | 页面主标题 / 行动标题 (`title`) | `54–84 px` | `26–40 pt` | **Bold (`700`)**；行距 `1.12–1.18` |
| **第二顺位（导语提要）** | 导语 / 副标题 (`lead` / `subtitle`) | `28–36 px` | `13.4–17.3 pt` | **Regular (`400`)** 或 *Italic*；**必须比正文大至少 5–6 px**，承接标题与展品 |
| **第三顺位（连续精读）** | 双栏/主栏正文 (`body`) | `22–26 px` | `10.6–12.5 pt` | **Regular (`400`)**（大段正文绝不加粗）；行距 `1.48–1.55` |
| **第四顺位（旁注与模块）** | 2 轨旁注 / 卡片内文 / 表格单元 (`body_sm`) | `19–22 px` | `9.1–10.6 pt` | 正文用 **Regular**，模块小标与核心数值用 **Bold** |
| **第五顺位（刻度与导引）** | 顶部 Kicker / 刻度坐标 / 图注 / 页码 (`caption` / `annotation`) | `15–18 px`（**底线 `14 px`**） | `7.2–8.6 pt`（**底线 `6.7 pt`**） | 导引与刻度用 **Bold** 宽字距大写；**严禁出现 `< 14 px` 的微缩字** |

字重一列是 A 重压型的示例取值。实际字重按所选主题与项目声明的 `W(S)`（重压 / 反压 / 单一字重）取，见 [Type System](../../framework/TYPE_SYSTEM.md)；`14px` 底线不随系统改变。

## 与主题和品牌组合

| 层 | 贡献 |
|---|---|
| Layout | A4 画布、六轨/四列网格、文字与图片区域、解构几何层、占位符、跨页关系 |
| Style | 摄影叙事、阅读节奏、信息表达、开放式表格与背景气氛 |
| Brand | 真实标识、身份色（如骑士蓝、冷炭黑等）、品牌字体及其使用规则 |

可以同时选择一个本 Layout、一个 Style 和一个 Brand。原型中的中性色、安全字体和临时字号只用于展示结构，最终身份与成品阅读尺度由项目确定。照片与示例文案不会成为后续项目必须保留的内容。

用户明确选择本包版式，或 Create Template 已在当前对话交付这个根时，将完整绝对工作区作为现有 Layout 类型的 `explicit` 输入；沿用所选 ppt-master runtime 的应用流程。传根目录，不只传内部 `templates/`；不因名称相似而搜索或冒充内置模板。

| `03x_content_deconstruct` | **解构棋盘格蒙版与全幅摄影（新增）**；满版摄影叠加阶梯状实色与半透明网格色块及 `↗` / `< >` 视觉导引，留出中央对角线视觉走廊 |
| `03y_content_atelier` | **留白宣言与切片巨字对撞（新增）**；上部大留白配偏置宣言与右上微字索引，下部左侧粗黑框肖像对撞右侧水平切片巨字与正负形剪影 |
| `03z_content_pillars` | **深色底场与阶梯裁切数字柱（新增）**；满版深色底场之上错落升起四根不等高白柱，白柱右下边缘裁切巨型衬线数字 `1–4`，负空间承载说明 |
| `03aa_content_immersion_left` | **跨屏沉浸左页**；满版摄影、刊头序号与大标题直接压在图上，与右页共享同一裁切坐标 |
| `03ab_content_immersion_right` | **跨屏沉浸右页**；延续左页照片，底部白色阅读面板承接正文，蓝线作为图与文的接缝 |
| `03ac_content_feature_folio` | **整页影像专题**；单一全幅照片占满页面，标题、导语与来源直接排在图上，适合章节开篇或高潮页 |
| `03ad_content_feature_panel` | **图文专题侧栏**；全高照片与右侧实色阅读面板垂直对分，蓝色轴线分隔氛围与证据 |
| `04_ending` | 结束页；短句、联络信息或后续行动 |

第二辑与第三辑的选型与细节方法见 [Editorial Rhythm](../../framework/EDITORIAL_RHYTHM.md)。节奏来自重复与变化、尺度极差、正负形穿插、空间疏密和页面序列，不是给每个区块换颜色。示例中的照片、蓝金身份与具体英文均不进入安装清单。

六轨是对齐系统，不代表六栏正文。双栏、4＋2、四列矩阵或其他组合应由实际行长与阅读尺度决定；内容过量时换版、重组或续页，避免靠缩小文字塞满占位区。

跨页使用同一照片与同一总裁切区域，左页显示前半、右页显示后半。装订顺序是偶数左页、奇数右页；两页各自居中裁图不构成连续全景。关键人物、文字和细节避开中缝，拼接预览应核对地平线与主体连续性。

表格原型预留灵活对象区域，不固定项目数据、行列或费用字段。下游再根据内容构造原生可编辑表格；选择横线风格时，可见横线与原生单元格边框需一致。信息图同样在下游根据实际关系建立。

## 展示与导出

带照片、排好文案的本地展示（例如 `projects/a4_editorial_preview_20261020/`）用来观察真实密度、裁切与节奏。该目录被 Git 忽略，克隆仓库后未必存在，也不随工作区安装。可复用源位于 `workspace/templates/`，结构预览 PPTX 位于工作区 `exports/`，后者只作为评审证据。

规范画布为 `1240×1754`，但当前 ppt-master 导出器以 96 dpi 换算，格式名 `a4` 不自动保证物理 `210×297 mm`。需要真实 A4 时保留原始已验证导出，另存完整归一化副本：同时缩放 Master、Layout、Slide 的几何、文字和对象尺寸，再核查物理页宽高、占位对齐、实际字号及渲染效果。只改页面尺寸会破坏排版。

图片贴到画布边缘表示视觉出血；商业印刷所需的裁切外出血和 PDF 页面框仍按实际印刷要求处理。
