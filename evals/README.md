# Evals — 证明本包比单用 ppt-master 更好

本包的目标是：同一个 brief，用本包做出来的 deck 比单用 ppt-master 更好。这里给出检验它的方法：同题 A/B、盲评、客观指标。修改 SKILL.md、主题 spec 或 Layout 之后跑一遍，确认提升还在。

## 1. 对照设置

| 组 | 安装 | 调用方式 |
|---|---|---|
| A（基准） | 只有 ppt-master | 「用 ppt-master 做……」，风格只用文字描述（如「瑞士国际主义风」） |
| B（本包） | ppt-master + ppt-master-themes | 「用 ppt-master-themes 做……」，同样的风格描述 |

两组的宿主、模型、effort、素材、画布、页数上限都相同，route 都用 Default（或都用 Quick）。每个 brief 至少各跑一次；有条件时各跑两次，看稳定性。

## 2. 题目

见 [briefs.md](briefs.md)。四道题分别覆盖：有现成主题的 A4 手册、16:9 决策稿、没有现成主题的瑞士风派生方言、强视觉画册。每道题都附同一份素材，两组不能有差别。

## 3. 打分

1. **客观指标**：对两组的 `svg_output/`（或最终 SVG 目录）运行

   ```sh
   python3 evals/svg_metrics.py A=<A 项目>/svg_output B=<B 项目>/svg_output
   ```

   它统计最小字号与低于底线的文字、字号种数与尺度极差、字体家族数、同字号混用字重（`W(S)` 冲突）、圆角/胶囊/阴影/渐变、颜色数。这些是证据，不是结论：主题明确要的斜体或渐变不算扣分。
2. **盲评**：把两组导出的联系表（每页缩略图排成一张）去掉标签、随机命名为 X / Y，交给没参与生成的人，或一个全新的 agent 会话，按 [rubric.md](rubric.md) 打分。评审者不知道哪组用了本包。
3. **不变量**：两组都要过 [SKILL.md](../SKILL.md) §8.1 的六条不变量；任何一条不过，该组这道题记为不合格，不进入品质比较。

## 4. 判定

- B 在 rubric 总分上高于 A，且没有任何一个维度比 A 低超过 1 分，记为「提升成立」。
- 四道题中至少三道提升成立，才算本包达到目标。
