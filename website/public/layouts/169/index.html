THE LOGIC / 设计逻辑

04

结构不动，
语气可换。

Layout 管结构，Style 管语气，Brand 管身份。
演示的节奏来自页与页之间的温度变化。

01 / VOICE

主题只换四样东西

底色、两种字体声音、一个结构母题、翻页节奏。版式的网格、占位符与阅读顺序保持不变，所以换主题不用重排。

02 / GRID

六轨与四模块轴

3＋3 承载双栏论述，4＋2 安排证据与旁注；四条模块轴对齐时间线、巨型数字与错位支柱。栏宽服务内容，不把文字切成窄条。

03 / NUMBERS

数字是排印，不是瓷砖

不用 KPI 卡片、图标墙或“线条＋色块”模块。标题、章节号与数字之间至少拉开 1.6 倍尺度，证据页按「标题 → 展品 → 注释 → 来源」排列。
