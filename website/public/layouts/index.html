THE LOGIC / 设计逻辑

05

有秩序，
才有自由。

Layout 管结构，Style 管表达，Brand 管身份。
三个部分各司其职，才能在新的内容里继续成立。

01 / RHYTHM

把翻页当作节奏

全幅摄影展开情绪，双栏正文承接阅读，先锋解构制造转折，图解与表格收拢信息。

02 / READING

六栏与四列是对齐的尺度

用 3+3 容纳长文，用 4+2 安排主次，用四列矩阵组织刊头与指标。栏数服务内容，不把正文切成窄条。

03 / OVERPRINT

交错处保留呼吸与透明

色块、画框与影像交错时采用多级透明度（1.0 / 0.58 / 0.34）阶梯叠透，让底层肌理与网格边界同时可见。
