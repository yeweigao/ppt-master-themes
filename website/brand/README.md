# Editorial Window / 展景

这套摄影编辑主题增强包的网站标志。字标以 THEMES 为主位，for PPT Master 只说明适配关系；该图形不代表上游 PPT Master 的身份。金色竖向取景框与向右下展开的墨蓝边框构成一个开放的窗口，借用摄影取景与翻页的关系。上下两个断点保持相同的 7 单位间隔，框线宽度同样为 7；右侧错位也为 7。图形内部不添加正文横线。

- 标准版：`../public/assets/brand/mark.svg`，白底使用，金色 `#D9AE32` 与墨蓝 `#14263A`。
- 反白版：`../public/assets/brand/mark-inverse.svg`，深色底使用，金色 `#E8C75A` 与白色。
- 单色版：`../public/assets/brand/mark-mono.svg`，用于单色输出。
- 浏览器图标：`../public/assets/favicon.svg`，深色圆角底使用同一图形。

原始 viewBox 为 64 × 72，保持等比缩放；外部至少留出一根框线的空白。页眉建议高度 36–40 CSS px；16 px 等小尺寸使用单独校准的 favicon。不要旋转、压扁、拆分图形或在窗口内添加细碎装饰。该标志用于主题包自身，制作客户项目时仍使用客户核对过的品牌标识。

首页、版式实验室与图片来源页直接引用同一标准 SVG，不维护多个手绘副本。对图形作调整时同步更新反白、单色与 favicon。
